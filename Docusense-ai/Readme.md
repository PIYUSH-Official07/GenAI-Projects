# DocuSense AI 📄🤖

**DocuSense AI** is an intelligent PDF chatbot powered by **ChromaDB**, **LLaMA2**, and **RAG (Retrieval-Augmented Generation)**. It allows you to upload any PDF document and instantly ask questions to get accurate, context-aware answers directly from the content of the document.

---

## Features 🌟

- **Instant PDF Analysis**: Upload any PDF and index it into **ChromaDB** for fast, relevant retrieval.
- **AI-Powered Responses**: Ask questions about the PDF, and get intelligent answers generated using **LLaMA2**.
- **Seamless User Interface**: Built with **Streamlit**, allowing a smooth and interactive experience.
- **Scalable**: Designed to handle large documents and provide precise results using the latest AI techniques.
